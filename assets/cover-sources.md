# Cover artwork references

`cover-v3.jpg` is an ImageGen edit of `cover-v2.jpg`, preserving the layout and replacing the generic agent header icons with referenced product marks.

- Codex: `icon-codex-light.png` from the installed official ChatGPT desktop app; [Codex](https://openai.com/codex/).
- Claude Code: Claude starburst from the installed official Claude desktop app; [Claude](https://claude.com/).
- Antigravity: [official full-color press icon](https://antigravity.google/assets/image/brand/antigravity-icon__full-color.png).
- Qoder: icon from the installed official Qoder desktop app; [Qoder](https://qoder.com/).
- Pi coding agent: [official website logo](https://pi.dev/logo-auto.svg).
- Kimi Code: [official extension logo](https://raw.githubusercontent.com/MoonshotAI/kimi-code/main/apps/vscode/webview-ui/public/kimi-logo.png).
- Devin CLI: [Devin product favicon](https://devin.ai/favicon.svg).

Product marks identify the supported tools and belong to their respective owners. The artwork uses rasterized visual reproductions; it is not a source of official vector logo assets.
